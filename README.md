# Minesweeper

A modern, feature-rich implementation of the classic Minesweeper game built with vanilla JavaScript, HTML, and CSS.

## Features

- **Timer & Mine Counter**: Track your progress with a built-in timer and remaining mine counter
- **Smart Game Controls**: New game button, flag system with right-click, and auto-reveal for blank areas
- **Professional UI**: Clean, responsive design that works on desktop and mobile devices
- **Robust Game Logic**: Proper win/loss detection, click prevention on revealed tiles, and mine proximity calculation

## How to Play

1. **Start the Game**: Game starts on random difficulty for now.
2. **Reveal Tiles**: Left-click to reveal tiles. Numbers show how many mines are adjacent
3. **Flag Mines**: Right-click to flag suspected mines (🚩) or mark with question marks (?)
4. **Win Condition**: Reveal all non-mine tiles to win the game
5. **Avoid Mines**: Clicking on a mine (💣) ends the game

The timer starts on your first click, and the mine counter shows remaining unflagged mines. Use logic and deduction to safely navigate the minefield!

## Getting Started

Simply open `index.html` in your web browser to start playing. No installation or build process required!
